排名分计算公式

# 每场竞赛的排名分 (Rank Score) def rank_score(rank, total_participants): """归一化排名分：第1名得满分，最后一名得保底分""" if total_participants <= 1: return 100 normalized = 1 - (rank - 1) / (total_participants - 1) return 40 + normalized * 60 # 保底40分，满分100分 # 最终成绩 = 加权平均 def final_grade(comp_scores, improvement, report, community): """ comp_scores: 6场竞赛排名分的列表 improvement: 进步奖励分 (0-100) report: 代码报告分 (0-100) community: 社区贡献分 (0-100) """ avg_rank = sum(comp_scores) / len(comp_scores) return (avg_rank * 0.60 + improvement * 0.20 + report * 0.15 + community * 0.05)

关键设计原则

  • 保底分机制：即使排名靠后也能获得40%的基础分，避免零分焦虑
  • 进步奖励：鼓励持续迭代，而非一次定胜负
  • 代码审查：防止刷分作弊，确保真正理解算法
  • 每日提交上限：每场竞赛每天最多提交3次，防止穷举搜索
  • 公开排行榜 + 隐藏测试集：排行榜基于公开测试集，最终评分基于隐藏测试集
